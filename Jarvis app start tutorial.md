**Run:** `python -m uvicorn server.api.main:app --reload --host 0.0.0.0 --port 8000`

## 3. open project in android studio

**project path:** `C:\Users\acer\Documents\jarvis_slm\android_app\JarvisAndroid`

- Select the mobile.
